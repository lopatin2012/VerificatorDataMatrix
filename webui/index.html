Как работать с Честным Знаком
  • Проверка выполняется только по кнопке — автоматически код никуда не отправляется.
  • Нужен интернет и доступ к mobile.api.crpt.ru; вне РФ сервис может быть недоступен.
  • Для проверки нужен полный код маркировки, включая криптохвост (AI 91/92/93).
  • «Найден, проверка не пройдена» — код есть в ГИС МТ, но криптохвост не подтверждён.
  • Сведения информационные и не являются официальным подтверждением подлинности.
