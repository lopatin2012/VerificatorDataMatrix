# DataMatrix Verifier

Верификатор штрих-кода **GS1 DataMatrix** (греддинг по ISO/IEC 15415):
поиск кода на изображении/в камере, декодирование содержимого,
оценка качества нанесения и вывод результатов в удобном интерфейсе.

## Возможности

- **Дашборд «светофор»**: большая сцена с кодом, круглый индикатор качества
  (0–100), вердикт ГОДЕН/БРАК, мини-полосы ключевых параметров.
- **Сцена**: зум, поворот, переключение канала (Цвет/Серый/ИК), heatmap —
  проблемные зоны обводятся цветными контурами прямо на изображении.
- **Вкладка «Дефекты»**: карточки проблем с иконками и рекомендациями;
  кнопка «Показать на коде» приближает проблемную зону.
- **Вкладка «Данные»**: чипы GTIN/SN/... с кнопками «Копировать».
- **Вкладка «Отчет»**: формирование PDF-отчёта (reportlab).
- **История**: лента миниатюр последних проверок (цветные рамки ОК/Брак)
  и итоговая строка «Проанализировано: N кодов».
- Поиск и локализация DataMatrix в кадре/изображении.
- Декодирование GS1-содержимого через `zxing-cpp`; для повреждённых кодов —
  восстановление сетки модулей и декод через `is_pure`.
- Оценка параметров по ISO 15415 (контраст, отражение, неоднородность сети,
  осевая неоднородность, рост печати, фиксированный шаблон, свободная зона
  и др.) с грейдами 0–4 и общим классом.
- UI на Tkinter (файл + камера) и CLI-режим.

## Установка

Используйте venv из репозитория (`.venv`, Python 3.13). Внутри репозитория
`python` в PATH уже резолвится в `.venv\Scripts\python.exe`.

```
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

GUI:
```
.venv\Scripts\python.exe main.py --gui
```

Web-сервис (доступен любому в сети, порт 8000):
```
.venv\Scripts\python.exe main.py --web --host 0.0.0.0 --port 8000
# или напрямую
.venv\Scripts\python.exe webapp.py --host 0.0.0.0 --port 8000
```
В браузере: загрузка файла или перетаскивание изображения, съёмка с камеры
(getUserMedia), дашборд с gauge/вердиктом/дефектами, скачивание PDF-отчёта.

Один файл:
```
.venv\Scripts\python.exe main.py --file samples/G4_1.jpg
```

Папка с изображениями:
```
.venv\Scripts\python.exe main.py --dir samples
```

Калибровка (мкм/пиксель) задаётся флагом `--um-per-px` или полем в UI.
По умолчанию 10 мкм/пиксель.

## Структура

- `main.py` — CLI / запуск GUI / web-сервис.
- `ui.py` — интерфейс Tkinter.
- `webapp.py` — Flask-сервис (REST: analyze / pdf / version).
- `webui/` — фронтенд (HTML/CSS/JS: загрузка, камера, heatmap, дашборд).
- `visual.py` — построение изображения с heatmap (общее для UI и web).
- `report.py` — официальный PDF-отчёт (с изображением кода, рамкой вокруг
  кода, таблицами и Unicode-шрифтом).
- `version.py` — версия приложения.
- `verifier.py` — оркестрация пайплайна и итоговые данные.
- `gs1.py` — разбор GS1 AI.
- `core/detect.py` — поиск символа и построение сетки модулей.
- `core/decode.py` — декодирование (zxing + сетка).
- `core/grade.py` — грейды параметров по ISO 15415.
- `samples/` — тестовые изображения G0–G4/ERROR.

## Ограничения

- Грейды приблизительные (не повторяют калибровку эталонного Axicon).
- `G4_2.jpg` (белый код на тёмно-синем фоне с перспективой) пока не
  распознаётся стандартным пайплайном.

## Нейросетевой локатор (дополнительно)

Модель ResNet18 (pretrained) с головой регрессии 4 углов, обучена на
`shortery/dm-codes` (300 изображений, лицензия MIT) на RTX 5070 Ti
(данные: `training/train.py`, оценка: `training/evaluate.py`).
Итог: средняя ошибка углов ~168 px при исходном разрешении, область кода
накрывается в 96% случаев.

- Веса: `models/dm_corners.pth` (обучаются в `training/`).
- Инференс: `core/nn_locator.py` (torch, lazy-import).
- Используется как **последний fallback-локатор** в `core/decode.py`:
  NN находит область → вырезается кроп с запасом → по кропу работает
  классический пайплайн (zxing + сетка модулей).
- Если torch не установлен — локатор просто пропускается (приложение
  работает без него).
- Замечание: модель обучалась на «тёмный-на-светлом» фото кодов;
  инвертированные коды (белый-на-тёмном, как `G4_2`) пока не
  локализуются.
